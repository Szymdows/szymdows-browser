Szymdows Browser Test Page

This is a test HTML file for the Szymdows Browser. If you're seeing this properly formatted, then the HTML parser and renderer are working!

About This Project

Szymdows Browser is a learning project to understand how web browsers work. It's built using a combination of Rust for the parser and C++ for the renderer.

Technical Details

The browser currently supports only h1,2,3,4,5,6 and p tags. The parser is written in Rust and uses a simple character-by-character parsing approach.

Future Plans

I want to add support for more HTML tags like div, span, and a. Eventually I'd like to add CSS support and maybe even JavaScript, though that will be really challenging.

Known Limitations

Nested tags don't work yet. I'm still figuring out how to properly handle the tree structure when tags are nested inside each other.
